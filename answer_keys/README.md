# MyTZStudies worked answer keys

Every one of the **60 distinct exams** currently in `exams/` has a corresponding worked key. Duplicate filenames and copies are grouped into the same exam in the website catalogue.

| Level | Keys |
|---|---:|
| Standard 4 | 17 |
| Standard 7 | 13 |
| Form 2 | 15 |
| Form 4 | 15 |
| **Total** | **60** |

The first page is a standalone MyTZStudies.com advertisement with a clickable website link. Page two contains the subject, code, level, year, NECTA exam board and paper type. The following pages restate the questions and provide numbered steps, clearly marked final answers, study notes and section summaries. Kiswahili keys use Kiswahili explanations. Writing and literature questions include complete model responses; optional questions are included for practice too.

These are independently written study solutions, rather than official NECTA marking schemes. Official candidate-response reports and primary references were used to check difficult items. Incorrect or ambiguous printed questions are identified in the relevant solution, including assumptions and differences between the intended choice and the mathematically or linguistically correct answer. Model details that the question does not supply are identified as examples. The English Standard 7 paper labelled 2024 is a sample paper and is displayed as such.

## Editable source and rebuild

Each `solutions/*.json` records the source PDF filename and SHA-256, expected question parts, explanations, final answers and optional figures. The build rejects changed source papers, duplicate or missing question IDs, incomplete answers and unsupported font glyphs.

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-pdf.txt
.venv\Scripts\python.exe tools/build_answer_keys.py
.venv\Scripts\python.exe tools/review_answer_keys.py
```

To rebuild one key, pass its JSON path to `build_answer_keys.py`. The PDFs are written to `output/pdf/` and published into this directory under normalized `*-AnswerKey.pdf` names, which the website prefers. Older differently named keys remain available at their existing URLs.

`review_answer_keys.py` renders every page under `tmp/pdfs/review/` and checks the cover, metadata, final-answer count, page boundaries, missing glyphs and text overlaps. Inspect the rendered pages visually after changes; geometry checks cannot judge diagram labels or the quality of a page break. Figures are stored in `figures/` and generated by `tools/draw_math_figures.py`.
